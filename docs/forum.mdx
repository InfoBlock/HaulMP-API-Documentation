# Forum (public)

**Base URL:** `https://forum.haulmp.com/api/forum`

Only a few endpoints are public. All other forum endpoints require sign-in and are not documented here.

## Categories

<Endpoint method="GET" base="https://forum.haulmp.com/api/forum" path="/categories" />

Returns the forum's sections and forums.

```bash
curl https://forum.haulmp.com/api/forum/categories
```

## Child-Categories & Threads

<Endpoint method="GET" base="https://forum.haulmp.com/api/forum" path="/c/{slug}?page=&sort=" />

Returns all Children and Threads of an Forum Category.

| Parameter | In | Description |
| --- | --- | --- |
| `slug` | path | The thread's slug |

```bash
curl https://forum.haulmp.com/api/forum/c/{slug}?page=&sort=
```

## Search & Activity

<Endpoint method="GET" base="https://forum.haulmp.com/api/forum" path="/search?q=" />

Search for an certain text within the entire forum

```bash
curl https://forum.haulmp.com/api/forum/search?q=
```

<Endpoint method="GET" base="https://forum.haulmp.com/api/forum" path="/activity?page=" />

See the recent activity on the forums

```bash
curl https://forum.haulmp.com/api/forum/activity?page=
```

## Member Profile

<Endpoint method="GET" base="https://forum.haulmp.com/api/forum" path="/u/{handle}" />

Get the profile of an member

| Parameter | In | Description |
| --- | --- | --- |
| `handle` | path | Member's username |

```bash
curl https://forum.haulmp.com/api/forum/u/{handle}
```

## Member List

<Endpoint method="GET" base="https://forum.haulmp.com/api/forum" path="/members?page=&sort=" />
